# Stars Elite Wood Industry Website

Static multi-page website for **Stars Elite Wood Industry LLC**.

## Project Overview

- Stack: HTML, CSS, vanilla JavaScript
- Architecture: static multi-page site (no framework runtime)
- Entry pages:
  - `index.html`
  - `about.html`
  - `products.html`
  - `services.html`
  - `quote.html`
  - `contact.html`
  - `404.html`
- Main assets:
  - `assets/css/styles.css`
  - `assets/js/main.js`

## Local Setup

1. Install Node.js 20+ and npm.
2. Install dependencies:

```bash
npm install
```

3. Start local dev server:

```bash
npm run dev
```

## Available Scripts

- `npm run dev`: start local development server (Vite)
- `npm run build`: create production build in `dist/`
- `npm run preview`: preview built output locally
- `npm run lint`: run JavaScript lint + formatting check
- `npm run format`: apply Prettier formatting

## Build Output

- Production artifact directory: `dist/`
- Generated by Vite multi-page build (`vite.config.mjs`)

## Deployment (Best Match: Netlify)

This repository includes `netlify.toml` with:
- build/publish settings
- extensionless page redirects
- security headers (CSP, X-Content-Type-Options, Referrer-Policy, HSTS, etc.)
- cache-control policies

### Netlify Steps

1. Connect this repository to Netlify.
2. Confirm:
   - Build command: `npm run build`
   - Publish directory: `dist`
3. Deploy.

## Alternative Hosting

- Apache/static hosting is also supported via `.htaccess` (rewrites, caching, headers).

## Forms

- Contact and quote forms submit to FormSubmit endpoints configured in:
  - `contact.html`
  - `quote.html`
